Manga Maker

Manga Maker is a lightweight drawing software project focused on optimization and extreme simplicity. It was designed for artists who use low-end devices, while still taking advantage of modern 8-core processors for better performance.

With a simple and fast workflow, Manga Maker aims to make digital drawing accessible without sacrificing essential tools.

Features
Lightweight and optimized performance
Designed for weak or low-end devices
Support for multi-core processors
5 different brush types
Up to 10 simultaneous layers
Simple and easy-to-use interface
Goal

The main goal of Manga Maker is to provide a smooth drawing experience with minimal hardware requirements, making digital art creation more accessible to everyone.
