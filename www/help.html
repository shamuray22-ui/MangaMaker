Documentação do MangaMaker

1. Introdução

O MangaMaker é uma aplicação web gratuita para criação e gerenciamento de desenhos e mangás. Desenvolvido com tecnologias modernas como Konva.js para canvas interativo, oferece ferramentas completas para artistas digitais. Compatível com dispositivos móveis e desktop, utilizando armazenamento local para persistência de dados.

Recursos Principais:

  • Desenho com pincéis personalizáveis e estabilização.
  • Gerenciamento de camadas para organização complexa.
  • Criação de mangás com capítulos e páginas.
  • Visualização em modo leitor.
  • Exportação e importação de projetos.

2. Iniciando

2.1 Galeria Principal

A galeria (index.html) é o ponto de entrada da aplicação, exibindo todos os projetos salvos.

Funcionalidades:

  • Criar Desenho: Inicia um novo projeto. Selecione "Draw" para arte única ou "Manga" para série com capítulos.
  • Salvar Galeria: Exporta projetos em JSON para backup.
  • Carregar Galeria: Importa projetos de arquivo JSON.
  • Limpar Galeria: Remove todos os projetos (irreversível).
  • Ajuda: Acesso a esta documentação.

Passos para Criar um Projeto:

  1. Clique em "Criar desenho".
  2. Escolha o tipo: Draw ou Manga.
  3. Insira um nome e confirme.

3. Tela de Desenho

A tela de desenho (draw-screen.html) utiliza um canvas Konva para criação artística.

3.1 Ferramentas Principais

  • Desfazer (Ctrl+Z): Reverte ação anterior.
  • Refazer (Ctrl+Y): Restaura ação desfeita.
  • Sair: Retorna à galeria com confirmação de salvamento.
  • Redimensionar: Ajusta dimensões do canvas (largura/altura).
  • Salvar (Ctrl+S): Salva trabalho na galeria.
  • Configurações: Abre painéis de ferramentas e camadas.

3.2 Ferramentas de Desenho

  • Caneta (Q): Desenha linhas suaves com estabilização.
  • Borracha (E): Remove traços.
  • Linha: Cria linhas retas.
  • Retângulo: Desenha formas retangulares.
  • Elipse: Desenha círculos/elipses.
  • Texto: Insere texto editável.
  • Seleção: Seleciona e move áreas/objetos.

3.3 Camadas

Organize elementos em até 10 camadas para controle preciso.

  • Gerenciar Camadas: Adiciona/remove camadas.
  • Visível: Alterna visibilidade.
  • Oculto: Torna camada invisível.
  • Mover para Cima: Reordena camadas.
  • Mover para Baixo: Reordena camadas.

Dicas: Use camadas para separar fundo, personagens e detalhes.

3.5 Navegação e Zoom

Use roda do mouse para zoom (0.1x a 21x). Toque duplo para zoom em dispositivos móveis. Arraste para pan.

4. Gerenciamento de Mangás

Para projetos de mangá (manga-screen.html), estruture seu trabalho em capítulos.

4.1 Criando Capítulos

  • Criar Capítulo: Adiciona capítulo com nome e número de páginas (máx. 30).
  • Páginas: Cada página é editada individualmente.

Fluxo:

  1. Na galeria, crie projeto "Manga".
  2. Em "Gerenciar Mangá", clique "Criar Capítulo".
  3. Defina nome e páginas.
  4. Clique no capítulo para editar páginas.

5. Visualização de Mangá

O preview (mangaPreviwe.html) simula um leitor de mangá.

  • Página Anterior: Navega para página anterior.
  • Página Seguinte: Navega para página seguinte.
  • Selecionar Capítulo: Escolhe capítulo.

Uso: Clique em mangá na galeria e selecione "Visualizar".

6. Configurações e Salvamento

Configurações são salvas automaticamente por projeto.

  • Salvamento Automático: Configurável em minutos (padrão 1 min).
  • Qualidade de Pixel: Ajusta resolução de renderização.
  • Estabilização: Suaviza traços.
  • Referências: Importe imagens como fundo via "Referência".

7. Atalhos de Teclado

  • Ctrl+Z: Desfazer
  • Ctrl+Y: Refazer
  • Ctrl+S: Salvar
  • Ctrl+C: Limpar Canvas
  • Q: Caneta
  • E: Borracha
  • Setas: Rotacionar canvas

8. Dicas Gerais

  • Salve frequentemente para evitar perda de dados.
  • Use camadas para projetos complexos.
  • Para mobile: Otimizado para toque; use mouse para precisão.
  • Armazenamento: Dados salvos localmente via localStorage/localForage.
  • Backup: Exporte galerias regularmente.

9. Solução de Problemas

  • Desenho não salva: Verifique espaço em disco e permissões.
  • Ferramentas não respondem: Recarregue página; verifique console (F12).
  • Mangá sem capítulos: Adicione capítulos primeiro.
  • Performance lenta: Reduza qualidade de pixel ou camadas.

10. Suporte e Contribuição

Para bugs ou sugestões, verifique o console do navegador. Código fonte disponível para contribuições.
